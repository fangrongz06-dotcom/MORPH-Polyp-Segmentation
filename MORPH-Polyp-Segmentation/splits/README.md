# Local split manifests

Run `python scripts/prepare_data.py --data_root /path/to/dataset` from the
repository root. It writes `local/train.csv`, `local/test_<dataset>.csv`,
`local/development.csv`, `local/development_fit.csv` and a content audit.
These files contain local dataset records and are excluded from Git.

The script preserves the supplied PraNet training/test partition. It checks
900 Kvasir + 550 ClinicDB training records and 100/62/380/196/60 test records.
The SHA-256 development ranking uses key 1234 and selects 90/55 source IDs.
No individual image IDs, experimental scores or historical audit results
are bundled with the code release.

CSV columns are `dataset,filename`, with optional `mask_filename` when the
mask extension differs. Filenames must be basenames. Original image IDs
are the filename stems and remain strings. BKAI has a separate manifest
generated by `scripts/prepare_bkai.py` after binary GT preparation.
