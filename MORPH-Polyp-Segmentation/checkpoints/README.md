# Checkpoints

Download the official [SAM ViT-B checkpoint](https://dl.fbaipublicfiles.com/segment_anything/sam_vit_b_01ec64.pth)
and place `sam_vit_b_01ec64.pth` in this directory.

MORPH training checkpoints are saved to `runs/morph/<seed>/checkpoint_last.pth`.
Weights are excluded from Git. Public trained weights can be distributed through
GitHub Releases, Zenodo or Hugging Face and linked from the main README.
